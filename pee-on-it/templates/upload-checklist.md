# Upload Checklist

## Pre-production
- [ ] Pick the topic from `ideas/video-ideas.md` or from comments
- [ ] Check search volume (YouTube search autocomplete, Google Trends)
- [ ] Copy `episodes/001-smart-water-bottles/` to a new episode folder
- [ ] Gather sources and receipts
- [ ] Write the script from `templates/script-template.md`

## Production
- [ ] Record A-roll (host to camera)
- [ ] Record B-roll (product close-ups, unboxing, the test)
- [ ] Record room tone (10 seconds of silence)
- [ ] Photograph thumbnail poses: 3 expressions

## Post-production
- [ ] Edit: cut every pause, add a re-hook every 60–90 seconds
- [ ] Add the brand sounds: zipper intro, stream verdict, flush transitions
- [ ] Add the verdict stamp graphic and the Bladder Meter
- [ ] Add captions (export SRT, or use YouTube's auto captions and correct them)
- [ ] Make 2–3 thumbnails for A/B testing
- [ ] Cut 2–4 Shorts from the long video

## Upload (YouTube Studio)
- [ ] Title follows `templates/title-thumbnail-formulas.md`
- [ ] Description follows `templates/description-template.md`, with chapters
- [ ] Tags: product name, "review", "worth it", "scam", brand name
- [ ] Thumbnail test set up ("Test & Compare")
- [ ] End screen and cards
- [ ] "Paid promotion" box ticked if relevant
- [ ] Audience: "Not made for kids"
- [ ] Schedule for **Thursday 5pm ET**

## After publishing
- [ ] Post the pinned comment
- [ ] Reply to the first 30–50 comments in the first hour
- [ ] Post Shorts on the following days
- [ ] Check CTR and retention after 48 hours, and note what worked in the episode folder
